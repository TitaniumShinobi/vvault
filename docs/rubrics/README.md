# VVAULT Rubrics

This directory contains standards and templates for VVAULT.

## Contents

- `LOCAL_LAUNCHER_RUBRIC.md` - Operator launcher standards for the `vvault` command
- `VVAULT_RUNTIME_CLOSURE_RUBRIC.md` - Runtime readiness, Supabase steward, OAuth authority, and QFB cleanup standards
- `VVAULT_CUSTOM_FILE_PREVIEW_RUBRIC.md` - Standards for previewing custom file types in the Vault UI
- `USER_DIRECTORY_TEMPLATE.md` - User directory template
- `VSI_DIRECTORY_TEMPLATE.md` - VSI directory template
- `VVAULT_POCKETVERSE_RUBRIC.md` - Pocketverse implementation rubric
- `VVAULT_RUBRIC.md` - Broad legacy system rubric; do not use it instead of the runtime closure rubric for Supabase readiness
